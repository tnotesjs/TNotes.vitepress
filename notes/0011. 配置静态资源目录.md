## 1. 概述

VitePress 的静态资源（图片、favicon 等）默认放在 `.vitepress/public` 目录中。

## 2. public 目录

```
.vitepress/
└── public/
    ├── logo.svg
    └── favicon.ico
```

`public` 目录中的文件会被原样复制到构建产物根目录。

## 3. 引用静态资源

在 Markdown 中以绝对路径引用：

```md
![logo](/logo.svg)
```

或使用 base 路径（部署到子路径时）：

```md
![logo](/base/logo.svg)
```

## 4. 图片资源

```ts
export default defineConfig({
  base: '/', // 站点部署路径
})
```

使用 `base` 配置可以控制静态资源在部署时的路径前缀。
